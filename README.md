# RecoverNode free tools

Free, open-source tools from [RecoverNode](https://www.recovernode.com) for people who run their own Linux servers.

| Tool | What it does |
|---|---|
| [Linux Resilience Audit](resilience-audit/) | A read-only script that checks a server for the problems that quietly take sites down: certificate renewals that will not happen, Docker ports bypassing UFW, unrotated logs, flapping services, firewall rules lost at reboot, single DNS resolvers, clock drift. Each finding includes a one-line fix. |

Each tool has its own README and license.
